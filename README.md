# rksmp-modules-4-5-6

Практические задания по дисциплине «Проектирование и разработка мобильных приложений на языке Kotlin».

Студент: Начинкин Илья Сергеевич, группа ИКБО-65-23 (РТУ МИРЭА, ИИТ, кафедра МОСИТ).

## Структура репозитория

- `module4/` — 14 практических заданий: корутины и Flow, сервисы, WorkManager, геолокация, AlarmManager/BroadcastReceiver и сенсоры.
- `module5/` — 4 практических задания: файловое хранилище, Scoped Storage, MediaStore, Room (SQLite) и Preferences DataStore.
- `module6/` — 7 практических заданий и серверная часть сквозного проекта: Retrofit, Ktor Client/Server, PostgreSQL (Neon), JWT и BLE.

Каждый каталог `taskXX_*` содержит исходный код соответствующего задания. Подробные описания и листинги приведены в отчётах по модулям.
